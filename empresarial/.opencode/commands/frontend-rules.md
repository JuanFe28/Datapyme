# INSTRUCCIÓN OBLIGATORIA DE DISEÑO FRONTEND
Antes de generar o modificar HTML, plantillas Jinja2, CSS o componentes JavaScript en Datapyme:
1. Lee y aplica estrictamente `empresarial/design/SKILL_RULES_ENFORCED.md`.
2. PROHIBIDO "cards nested in cards" y cajas innecesarias.
3. PROHIBIDO párrafos largos o jerga interna dentro de las tarjetas.
4. Aplica la regla de 3 elementos por KPI (etiqueta, cifra tabular 28-32px, badge compacto).
5. Usa la estructura de 3 bloques: Header con Segmented Pill, Franja Unificada de Métricas + Hero con Tabs, y Tabla Operativa con Slide-Over Drawers.
